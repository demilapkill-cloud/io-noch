# Летопись бессонниц — сервер мировой таблицы

Игра работает и без него: без адреса летопись остаётся здешней — десяток
лучших своих забегов, что живут в самом браузере. Сервер надобен лишь затем,
чтобы забеги встали вровень с чужими.

Здесь два пути на выбор. Уговор с игрою у них один и тот же, так что менять
одно на другое можно когда угодно, не трогая игры.

## Путь первый: воркер Cloudflare (своей машины не надобно)

Бесплатно, без своего сервера и без присмотра.

```sh
npm i -g wrangler
wrangler login
cd server
wrangler kv namespace create BOARD     # выдаст id — вписать в wrangler.toml
wrangler deploy
```

`wrangler deploy` напечатает адрес вида `https://io-noch-board.<твоё>.workers.dev`.
Его и вписать в игре: **настройки → адрес летописи**.

## Путь второй: node на своей машине

Ни одной зависимости — довольно самого node.

```sh
node server/leaderboard.js            # слушает :8791
PORT=9000 BOARD_DB=/var/lib/board.json node server/leaderboard.js
```

Книга хранится рядом в `board.json`. Наружу его лучше выставлять через
nginx с https: игра ходит к летописи из браузера, а браузер не любит
незашифрованного соседства.

## Уговор

| дорога | что шлётся | что вернётся |
|---|---|---|
| `POST /api/register` | `{name, pass}` | `{token, name}` |
| `POST /api/login` | `{name, pass}` | `{token, name}` |
| `POST /api/score` | `{token, nights, thoughts, time, kills, level}` | `{ok, best, rank, rows}` |
| `GET /api/top?limit=50` | — | `{rows:[{name, nights, thoughts, time, at}]}` |

Имя — от двух до восемнадцати знаков (буквы, цифры, пробел, `_`, `.`, `-`),
пропуск — от четырёх. Пропуск нигде не хранится сам по себе: только солёным
хешем (scrypt у node, PBKDF2 у воркера). Токен живёт в браузере игрока.

Летопись помнит по одному забегу на имя — лучший. Лучшим считается тот, где
больше ночей; при равенстве ночей — больше мыслей, а при равенстве мыслей —
дольше время.

## О честности

Итог забега присылает сам клиент, и умелый гость волен прислать что угодно.
Так устроены почти все малые таблицы такого рода, и здесь избрано то же:
летопись эта — доброе слово между своими, не присяга. Коли понадобится
строгость, придётся считать забег на сервере, а это уже другая игра.
