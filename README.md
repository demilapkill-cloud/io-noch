# бесконечная ночь

Рогалик-ответвление «третьей ночи». killu × fable, 2026.

Главный герой — Ио, шарик света (Io the Wisp из Dota — единственное
заимствование, больше ничего из других игр). Ночи идут бесконечно, каждая
~90 секунд и тяжелее прежней. Бодрость — твоё здоровье: кошмары и молнии её
гасят, пойманные мысли возвращают. Уснул — ран окончен.

## Способности Ио

- **Спириты** — искры на орбите: кошмар, коснувшийся искры, рассеивается
  (искра гаснет на 4 секунды).
- **Нить (tether)** — клик рядом с кораблём: Ио привязывается и летит за ним,
  мысли тянутся к нему магнитом. Клик — отвязаться.
- **Релокейт** — пробел (двойной тап): телепорт в точку курсора, через 2,5
  секунды автоматический возврат обратно. Кулдаун — дуга вокруг ядра.
- **Оверчардж** — зажать shift (кнопка «заряд» на таче): орбита шире, искры
  быстрее, но бодрость горит.

## Рогалик

После каждой пережитой ночи — выбор одного из трёх «снов» (апгрейдов):
новая искра, шире хоровод, крепкий чай, длинная нить, лёгкость, глубокий
вдох, магнит для мыслей, толстое одеяло, редкое «второе дыхание».
Каждая третья ночь — шторм. Лучшая бессонница хранится в localStorage.
