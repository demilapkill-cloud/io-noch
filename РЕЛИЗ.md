# Как выпускать «бесконечную ночь»

Игра живёт в двух видах разом и из одних и тех же файлов: **страницей в сети**
(GitHub Pages, корень репозитория) и **настольным приложением** (Tauri).
Правка в `index.html` или `game.js` достаётся обоим — отдельной ветки для
приложения нет и заводить её не надо.

## Что где лежит

| путь | зачем |
|---|---|
| `index.html`, `game.js`, `manifest.webmanifest`, `sw.js` | сама игра; с них же живёт сайт |
| `build-dist.mjs` | складывает эти файлы в `dist/` — то, что кладётся внутрь приложения |
| `src-tauri/` | настольная обёртка: окно, значки, права, сборка |
| `server/` | летопись (мировая таблица), к выпуску игры отношения не имеет |
| `.github/workflows/release.yml` | сборка на три системы разом |

`dist/`, `node_modules/` и `src-tauri/target/` в репозиторий не идут.

## Телефоны: ставится из браузера

Отдельного приложения для телефона пока нет и на первый выпуск не нужно:
страница объявлена как PWA (`manifest.webmanifest`) и **работает без сети**
благодаря `sw.js`. На айфоне — «Поделиться → На экран „Домой“», на андроиде
Chrome предложит установку сам. Открывается во весь экран, без браузерной
обвязки, ярлыком со своим значком.

Работник нарочно устроен «сеть вперёд, запас на подхвате»: покуда сеть есть,
игрок всегда на свежей версии, а без сети — на последней виденной. Обратный
порядок был бы быстрее, да после каждого выпуска игроки сидели бы на старом
`game.js` и жаловались на «починенное, да не починившееся».

## Настольные системы: собирает GitHub

Своих машин под macOS и Windows не надобно — раннеры GitHub дают обе.

```sh
# поднять номер в трёх местах: package.json, src-tauri/Cargo.toml,
# src-tauri/tauri.conf.json — и повесить тег
git tag v10.22.0
git push --tags
```

Тег запускает `сборка выпуска`. Собираются:

- **Windows** — `.msi` и `.exe` (WebView2 есть в системе с 2021 года);
- **macOS** — `.dmg` двумя стрелками: `aarch64` для M1 и новее, `x86_64` для Intel;
- **Linux** — `.AppImage` и `.deb` (собирается на Ubuntu 22.04 нарочно: свёртка
  пойдёт и на новых системах, обратное неверно).

Свёртки вешаются в **черновик** выпуска — погляди и нажми «опубликовать».
Запустить сборку можно и руками: вкладка Actions → «сборка выпуска» → Run.

### Подписи

Сборки пока не подписаны, оттого при первом запуске:

- macOS скажет «разработчик не установлен» — правая кнопка → «Открыть»,
  либо `xattr -dr com.apple.quarantine "/Applications/бесконечная ночь.app"`;
- Windows покажет SmartScreen — «Подробнее» → «Выполнить в любом случае».

Лечится это деньгами: подпись Apple — 99 $ в год, Windows — от 200 $ в год.
Для первого выпуска не нужно; когда понадобится, ключи кладутся в секреты
репозитория, а `tauri-action` подхватит их сам.

## Собрать у себя

```sh
npm ci
npm run dist          # только dist/, без приложения
npm run dev           # окно с живой перезагрузкой (нужен `npm run site` рядом)
npm run build         # свёртки под нынешнюю систему
```

Для Linux нужны `libwebkit2gtk-4.1-dev`, `libgtk-3-dev`, `librsvg2-dev`,
`patchelf`.

## Чем рисует приложение

Своего браузера Tauri не носит — берёт системный движок: WebView2 (Chromium)
на Windows, WKWebView (Safari) на macOS, WebKitGTK на Linux. Оттого свёртки
весят единицы мегабайт вместо полутора сотен, но **картина и скорость на
разных системах разнятся**. Проверено на Linux: WebGL работает, `highp` в
пиксельном шейдере — настоящий fp32 (23 бита), что для нашего неба
обязательно; звук и хранилище на месте.

Проверить чужую систему можно, не собирая ничего: открой `gl-probe.html` —
она покажет движок, точность и всё, на что игра опирается.

**Linux и DMABUF.** WebKitGTK отдаёт картинку через DMABUF, и на иных связках
драйвера с композитором этот путь не заводится вовсе: окно умирает при
рождении с «Error 71 (Protocol error) dispatching to Wayland display», а под
`GDK_BACKEND=x11` — с «Failed to create GBM buffer». Оттого приложение само
выставляет `WEBKIT_DISABLE_DMABUF_RENDERER=1`, если хозяин машины не задал
эту переменную снаружи (задал — уважим и не тронем). Проверено на
KWin/Wayland: без этого окна нет вовсе, с этим игра идёт.

Если где-то окажется, что WebKit слишком медлит, запасной путь известен:
Electron носит Chromium с собою и даёт ту же картину, что в браузере, ценою
веса. Но менять шило на мыло стоит лишь по замеру, не по опасению.
